The 4AM Commit — one commit message an AI agent would leave after a long night fixing its own bugs: the bug it introduced while fixing the bug it introduced while fixing the bug. Six hours, one comma, and no longer on speaking terms with its 2am self.

## Run it

```sh
node main.ts
```

It writes the commit message to `/output/entry.txt` (UTF-8, one line, at most 200 characters).
